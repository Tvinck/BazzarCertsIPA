# BAZZAR Panel 0.1.0

Исходный компонент UIKit для iOS 15+, arm64. Светлая/тёмная тема, системные значки, масштабирование текста, закрытие экрана, кнопки с обработкой ошибки. Адреса: https://bazzar-serts.shop/ipa/ymhight и https://bazzar-serts.shop/#tariffs.

## GitHub Actions без Mac

Содержимое этой папки должно быть в корне отдельного репозитория, включая скрытую папку `.github`. Не загружайте ZIP как единственный файл: сначала распакуйте его. Workflow должен находиться по пути `.github/workflows/build-ios.yml` на основной ветке.

Откройте Actions → Build BAZZAR Panel → Run workflow. После успешного запуска скачайте артефакт `BAZZARPanel-ios-arm64-номер`. Внутри библиотека, конфигурация, хеши, список зависимостей, экспортируемых символов и сведения о сборке. Workflow также запускается при изменении исходников.

Секреты и сертификат для этой сборки не требуются. Библиотека ещё требует интеграции и подписи в составе приложения. Успех workflow не означает проверку запуска IPA. Исходный YMNight IPA сюда не загружается и не меняется.

## Статус

Исходники подготовлены на Windows. Компиляция с iOS SDK и запуск на iPhone пока не выполнены. Готовой dylib и изменённого IPA в этом пакете нет. Компонент не отключает чужие окна и не изменяет подписку приложения.

## Сборка

На Mac с установленным Xcode и iPhoneOS SDK: `bash build-macos.sh`. Результат: dist/BAZZARPanel.dylib и plist. Проверьте сообщения компилятора, затем подпишите библиотеку в составе тестового приложения.

## Подключение к приложению с исходниками

Можно включить BAZZARPanel.m и .h прямо в проект, а plist добавить в ресурсы основного приложения. В обработчике собственной кнопки вызовите `BAZZARPresentPanel(self)` из видимого UIViewController. Повторный показ поверх уже открытого экрана блокируется. Для отдельной dylib необходимо также обеспечить её загрузку и корректную подпись.

## Подключение к YMNight

Требуется отдельный адаптер для конкретной версии: найти текущую кнопку и её обработчик, подтвердить независимость от прочих функций, подключить новый экран и проверить исходник/копию на устройстве. Автоматический перехват всех кнопок, стартовые конструкторы и изменения YMNight здесь намеренно отсутствуют. Загрузка dylib сама по себе экран не открывает.

## Проверка перед выпуском

Сборка без ошибок; открыть и закрыть экран несколько раз; большие размеры шрифта; светлая/тёмная тема; VoiceOver; iPhone/iPad; переход на сайт и возврат; повторное нажатие; основные функции приложения до/после интеграции. Публикацию страницы на сайте и её доступность этот компонент не проверяет.

API показа: https://developer.apple.com/documentation/uikit/uiviewcontroller/present(_:animated:completion:)
